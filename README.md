# sustainable-supply-chain-tracker


##  Description
This project is a database-driven system to track supply chain operations and carbon emissions.

##  Features
- Product and supplier management
- Shipment tracking
- Automatic carbon emission calculation using triggers
- Dashboard visualization

##  Technologies Used
- HTML, CSS, JavaScript
- MySQL
- Gemini Canvas AI

##  Database Features
- Normalization up to 3NF
- Joins
- Trigger for emission calculation

##  Output
The system calculates emissions automatically when shipment data is added.
